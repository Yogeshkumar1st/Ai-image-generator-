## 2024-05-22 - DOM XSS via unescaped single quotes in innerHTML interpolation
**Vulnerability:** The gallery loading logic constructed HTML strings using template literals and inserted them into the DOM using `innerHTML`. While it used `encodeURIComponent` to sanitize the URL payload, this function does not encode single quotes (`'`). This allowed a payload containing single quotes to prematurely close the HTML attribute and inject arbitrary event handlers, resulting in Cross-Site Scripting (XSS).
**Learning:** `encodeURIComponent` is not sufficient for sanitizing user input when interpolated into single-quoted HTML attributes using `innerHTML`. It escapes most characters but leaves single quotes vulnerable to escaping the string context.
**Prevention:** Always use safe DOM API methods like `document.createElement()`, set properties directly (e.g., `img.src = url`), and attach event listeners programmatically (e.g., `img.onclick = ...`) rather than constructing raw HTML strings with `innerHTML`.
