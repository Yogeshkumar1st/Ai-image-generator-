## 2024-03-24 - DOM XSS via innerHTML in Gallery History
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found in the gallery history feature. The application used `innerHTML` to construct gallery items, interpolating the `item.url` property directly into the HTML string (`<img src="${item.url}" onclick="viewImage('${item.url}')">`). This allows an attacker who controls the URL to inject arbitrary HTML or break out of the `onclick` handler attributes to execute arbitrary JavaScript.
**Learning:** Using string interpolation with `innerHTML` is inherently unsafe when handling user-influenced data, even if it's considered "safe" or partially encoded data. JavaScript's `encodeURIComponent()` (used earlier in the flow) does not escape single quotes (`'`), meaning it's still possible to break out of single-quoted attributes like `onclick='...'`.
**Prevention:** Always use safe DOM manipulation APIs like `document.createElement()` and assign values directly to properties (`img.src`, `img.onclick`) rather than constructing HTML strings. This ensures the browser treats the input strictly as data, not executable code.
