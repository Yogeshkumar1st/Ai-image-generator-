## 2024-03-24 - DOM-based XSS in Gallery History
**Vulnerability:** The application stores generated image URLs in localStorage and renders them in the gallery using string interpolation in `innerHTML`: `<img src="${item.url}" onclick="viewImage('${item.url}')">`. If a malicious URL containing single quotes is injected (e.g., via user input or modified localStorage), it can break out of the `onclick` attribute and execute arbitrary JavaScript. JavaScript's `encodeURIComponent()` (used during generation) does not escape single quotes (`'`).
**Learning:** `innerHTML` with string interpolation for attributes is highly susceptible to DOM-based XSS when single quotes are not escaped or when the underlying input isn't properly sanitized. Even URLs should be treated as untrusted data when placed into DOM attributes.
**Prevention:** Prefer using safe DOM manipulation APIs (e.g., `document.createElement()`, setting `.src`, and using `.addEventListener()`) over `innerHTML` assignments when constructing elements from dynamic data.
