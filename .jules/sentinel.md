## 2024-05-24 - [DOM XSS via innerHTML and Unescaped Single Quotes]
**Vulnerability:** A DOM-based XSS vulnerability existed in `index.html` where user-controlled URLs from `localStorage` were interpolated directly into an `innerHTML` assignment: ``div.innerHTML = `<img src="${item.url}" onclick="viewImage('${item.url}')">`;``.
**Learning:** Even if URLs are generally safe or sanitized for HTML context, interpolating them into single-quoted event handler attributes (`onclick='...'`) within a template string creates an XSS vector because standard functions like `encodeURIComponent` do not escape single quotes ('). An attacker could inject `');alert('XSS');//` to break out of the string literal and execute arbitrary JavaScript.
**Prevention:** Always use DOM API methods (`document.createElement`, `setAttribute`, and attaching event listeners directly via properties like `element.onclick = function`) instead of string-based template rendering (`innerHTML`) when handling user-generated data, especially when constructing complex elements with inline event handlers.
