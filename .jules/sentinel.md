## 2024-05-27 - [High] Prevent XSS in Image Gallery
**Vulnerability:** The application was dynamically generating HTML in the `loadHistory` function using `div.innerHTML = \`<img src="${item.url}" onclick="viewImage('${item.url}')">\``. The `item.url` was obtained from `localStorage`, which could be tampered with. If `item.url` contained a single quote (`'`), it could break out of the string interpolation in the `onclick` handler and execute arbitrary JavaScript. For instance, `https://.../')-alert(1)-('...` would evaluate to `viewImage('https://.../')-alert(1)-('...')`.
**Learning:** String interpolation of external/untrusted data (even if originating from URL generation APIs or stored in local storage) into HTML strings, particularly within event handlers (like `onclick`), is highly vulnerable to XSS. Unescaped quotes (like single quotes here) are a common vector.
**Prevention:** Always use safe DOM APIs (like `document.createElement`, `element.src`, `element.onclick`) for dynamic element creation instead of `innerHTML`. When attaching event listeners, assign function references (e.g., `img.onclick = () => viewImage(item.url)`) rather than interpolating strings.
