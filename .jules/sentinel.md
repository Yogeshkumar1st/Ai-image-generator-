## 2024-06-24 - [XSS Mitigation in Dynamic UI Generation]
**Vulnerability:** The `loadHistory` function in `index.html` was dynamically constructing HTML strings using `div.innerHTML = \`<img src="${item.url}" ...>\`` where `item.url` was sourced from user-controlled `localStorage` (which was populated via URL encoding but lacked proper decoding/sanitization). An attacker could inject a payload with an unescaped single quote (`'`) to break out of the `src` attribute and execute arbitrary JavaScript (XSS).
**Learning:** Using `innerHTML` for dynamic content insertion, even when relying on browser features like `encodeURIComponent` elsewhere, is risky if quote escaping isn't guaranteed throughout the entire lifecycle. DOM APIs provide built-in escaping for attributes.
**Prevention:** Always use safe DOM manipulation techniques like `document.createElement()`, `element.textContent`, or direct property assignment (e.g., `img.src = value`) instead of interpolating variables into `innerHTML` strings.
