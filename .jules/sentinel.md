## 2024-05-24 - [Stored XSS in loadHistory]
**Vulnerability:** A Stored Cross-Site Scripting (XSS) vulnerability was found in the `loadHistory` function in `index.html`. Unsanitized user inputs from `localStorage` were concatenated directly into the DOM using `.innerHTML`. Specifically, while the URL might be passed through `encodeURIComponent`, that function does NOT escape single quotes (`'`). This allowed an attacker to break out of the `onclick='...'` attribute string boundary and inject arbitrary JavaScript.
**Learning:** `encodeURIComponent` is not a catch-all security panacea for XSS, especially when data is injected into single-quoted event handler attributes. Direct string concatenation with `.innerHTML` for user-controllable data is fundamentally insecure.
**Prevention:** Always use safe DOM APIs like `document.createElement`, setting properties directly (`img.src = item.url`), and attaching event listeners (`img.onclick = ...`) rather than concatenating HTML strings. This naturally avoids attribute breakout vulnerabilities.
