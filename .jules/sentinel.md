## 2024-07-11 - XSS via innerHTML and DOM Attribute Injection
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in the gallery tab where user input (history URLs) was unsafely injected into HTML attributes using template literals and `innerHTML` (`<img src="${item.url}" onclick="viewImage('${item.url}')">`). This allowed attackers to escape the quotes and inject arbitrary JavaScript (e.g., via the `onclick` handler).
**Learning:** Even when interpolating values directly into HTML attributes, `innerHTML` does not automatically escape quotes (like `'` or `"`), making it susceptible to XSS if the input is not sanitized or properly escaped.
**Prevention:** Avoid using `innerHTML` to build DOM elements dynamically, especially when incorporating user input. Use safe DOM manipulation methods like `document.createElement`, `element.textContent`, or direct attribute assignment (e.g., `img.src = item.url`), which automatically handle escaping and prevent script injection.
