## 2024-06-08 - Fix XSS in History Loading
**Vulnerability:** XSS vulnerability in `loadHistory` where `item.url` was interpolated directly into the `innerHTML` string using single quotes for the `onclick` handler `viewImage('${item.url}')`. Since `encodeURIComponent` does not escape single quotes, a user could craft a malicious payload in the prompt that would break out of the `onclick` handler string and execute arbitrary JavaScript. Furthermore, the URL generation contained a literal newline which also broke the `onclick` JavaScript parsing.
**Learning:** Never interpolate unescaped strings (especially URLs that might contain single quotes) directly into HTML attributes via `innerHTML`. Even if `encodeURIComponent` is used, it does not encode single quotes (`'`), leaving `onclick` attributes bounded by single quotes vulnerable.
**Prevention:** Use `document.createElement` and set DOM properties like `src` and event handlers like `onclick` directly, bypassing HTML parsing and preventing script injection.
