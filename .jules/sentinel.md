## 2024-05-24 - [CRITICAL] XSS via encodeURIComponent and innerHTML with Single Quotes
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in the application's history rendering logic (`loadHistory`). The application took user input, ran it through `encodeURIComponent`, and embedded the resulting URL into an `innerHTML` assignment within a single-quoted HTML attribute (`onclick="viewImage('${item.url}')"`).
**Learning:** `encodeURIComponent` does NOT encode single quotes (`'`). When combined with `innerHTML` and single-quoted event handler attributes, this allows an attacker to inject a single quote to break out of the string literal and execute arbitrary JavaScript. The assumption that `encodeURIComponent` makes data safe for all HTML contexts is flawed.
**Prevention:** Avoid using `innerHTML` to render user-generated content or dynamically constructed URLs containing user input. Instead, exclusively use DOM API methods (e.g., `document.createElement`, `element.src = value`, `element.onclick = handler`) which automatically handle proper escaping and prevent script injection.
