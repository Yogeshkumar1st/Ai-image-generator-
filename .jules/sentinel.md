## 2024-04-14 - Fix DOM XSS in Gallery History
**Vulnerability:** The application was vulnerable to DOM-based Cross-Site Scripting (XSS) in `index.html` where user-controlled generation history (the URL) was directly concatenated into the DOM via `innerHTML`. A payload using unescaped quotes in the URL could break out of the `onclick` attribute string and execute arbitrary JavaScript when the gallery was loaded.
**Learning:** `encodeURIComponent` does not encode single quotes (`'`). This allowed an attacker to inject payloads like `'-alert(1)-'` directly into single-quoted HTML attributes if string interpolation was used to construct HTML. This is a common pitfall when attempting to sanitize input for HTML attributes.
**Prevention:** Never use `innerHTML` with unsanitized user data, especially when constructing complex HTML strings with interpolated values. Always use secure DOM API methods (`document.createElement`, `setAttribute`, `element.property = value`, `addEventListener`) which inherently treat user input as data rather than executable code.
