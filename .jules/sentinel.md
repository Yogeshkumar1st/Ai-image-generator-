## 2024-05-24 - [DOM XSS via innerHTML]
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability existed in `index.html` where user-controlled image URLs from `localStorage` were rendered directly into the DOM using `innerHTML` within the `loadHistory()` function.
**Learning:** This vulnerability existed because the code prioritized brevity over security when rendering history items. Storing data in `localStorage` does not automatically make it safe; any data retrieved from it that originated from user input must be sanitized or safely rendered. Using string templates with `innerHTML` allows arbitrary HTML and JavaScript execution.
**Prevention:** Always use safe DOM API methods like `document.createElement()`, `element.setAttribute()`, and `element.appendChild()` when rendering dynamic content, especially if it originates from user input or storage mechanisms like `localStorage`. Avoid `innerHTML` unless the input is strictly validated and sanitized through a trusted library.
