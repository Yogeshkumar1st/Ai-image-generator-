## 2024-05-18 - [DOM-based XSS in Image Gallery]
**Vulnerability:** DOM-based XSS via `innerHTML` injection. The application renders user-provided image URLs and prompts from `localStorage` directly into the DOM using `div.innerHTML = \`<img src="\${item.url}" onclick="viewImage('\${item.url}')">\`;`. If an attacker crafts a malicious URL containing a single quote, they can break out of the `viewImage` parameter and execute arbitrary JavaScript when the image is rendered.
**Learning:** Using `innerHTML` with string interpolation is dangerous even if the outer variable seems harmless (like a URL). Single quotes (`'`) within the URL (e.g., encoded or raw) are not automatically escaped by `innerHTML`, allowing breakout from event handlers defined in HTML attributes like `onclick`.
**Prevention:** Always use `document.createElement` and set properties (like `src`, `onclick`, `textContent`) directly on the element object instead of constructing HTML strings with `innerHTML`. This ensures the browser treats the input as pure data rather than executable code or markup.
