## 2025-01-20 - [DOM XSS] Missing sanitization in innerHTML
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found in the `loadHistory` function in `index.html`. User-controlled input (`item.url` from `localStorage` "xhistory") was interpolated directly into an `innerHTML` string, specifically within an `onclick` attribute wrapper using single quotes. Because `encodeURIComponent` does not escape single quotes (`'`), payloads could inject raw JavaScript.
**Learning:** Avoid using `innerHTML` to build DOM elements when incorporating any user-controlled or external data, especially when constructing attributes. Functions like `encodeURIComponent` do not provide XSS protection for single-quoted contexts in HTML.
**Prevention:** Construct DOM nodes dynamically using standard DOM APIs like `document.createElement()`, and set element properties (like `.src`, `.textContent`, `.onclick`) directly instead of relying on string interpolation to render HTML safely.
