## 2024-05-06 - [Fix Stored XSS in History Rendering]
**Vulnerability:** A stored Cross-Site Scripting (XSS) vulnerability existed in the `loadHistory` function in `index.html`. The application iterated through user-provided history data from `localStorage` and constructed HTML dynamically using `innerHTML`. The `item.url` property was interpolated directly into an `img` tag's `src` attribute and an inline `onclick` handler (`onclick="viewImage('${item.url}')"`). An attacker could inject a malicious payload (e.g., `'');alert(1);('`) to break out of the single quotes and execute arbitrary JavaScript when the image was rendered or clicked.
**Learning:** Using standard JavaScript string methods like `encodeURIComponent` does not encode single quotes (`'`). This can create a false sense of security and lead to XSS vectors if unescaped components are interpolated into single-quoted HTML attributes via `innerHTML`.
**Prevention:** Always rely on secure DOM API methods (e.g., `document.createElement`, setting element properties, and attaching event listeners like `img.onclick = () => ...`) instead of `innerHTML` for rendering user-generated or external content.
