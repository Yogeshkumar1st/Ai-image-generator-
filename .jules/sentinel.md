## 2026-03-10 - encodeURIComponent does not escape single quotes
**Vulnerability:** A cross-site scripting (XSS) vulnerability was identified in the application's history loading functionality. The application used string interpolation with `innerHTML` to create `img` tags based on user-supplied input that had been passed through `encodeURIComponent`. Crucially, `encodeURIComponent` does not encode single quotes (`'`). This allowed for a malicious prompt to break out of single-quoted HTML attributes (e.g., `onclick='...'`) and inject arbitrary JavaScript.
**Learning:** Standard JavaScript `encodeURIComponent` does not escape single quotes (`'`). Interpolating user input into single-quoted HTML attributes using `innerHTML`, even if the input was processed with `encodeURIComponent`, is an unsafe practice that can lead to XSS.
**Prevention:** Always rely on secure DOM API methods (such as `document.createElement`, `element.setAttribute`, or assigning to properties like `element.src` and `element.onclick`) when building DOM elements dynamically with user-supplied data, instead of using `innerHTML`. This ensures that the data is treated as content rather than executable code.
