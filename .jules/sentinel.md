## 2024-08-09 - XSS in localStorage via innerHTML and inline event handlers
**Vulnerability:** Found a Cross-Site Scripting (XSS) vulnerability in `loadHistory()` in `index.html` where `item.url` retrieved from `localStorage` was interpolated directly into an `img` element's `src` attribute and inline `onclick` handler via `innerHTML`. A payload like `'-alert(1)-'` in the URL could break out of the single quotes and execute arbitrary JavaScript when the image was clicked.
**Learning:** Using `innerHTML` with unsanitized data from `localStorage` (which can be manipulated by an attacker or contain unescaped user inputs) is dangerous. Also, single quotes are not escaped by `encodeURIComponent()`, making them viable for attribute breakout if used in `onclick='...'`.
**Prevention:** Always use safe DOM manipulation APIs like `document.createElement()`, `element.src = ...`, and `element.addEventListener('click', ...)` instead of `innerHTML` and inline event handlers when building DOM elements dynamically with potentially untrusted data.
