## 2024-05-24 - DOM-Based XSS via innerHTML in Image Gallery
**Vulnerability:** The application was vulnerable to DOM-Based XSS in the `loadHistory` function. User-controlled image URLs from `localStorage` were directly interpolated into an HTML string and assigned via `innerHTML`, specifically within an `onclick` event handler. A payload containing a single quote in the URL could break out of the event handler attribute and execute arbitrary JavaScript.
**Learning:** Even though the image generation URL encodes the prompt using `encodeURIComponent`, this function does not escape single quotes (`'`). When this URL is later injected into an HTML attribute that uses single quotes (e.g., `onclick='viewImage(...)'`), the single quote from the URL acts as the closing quote for the attribute, allowing injected JavaScript to follow.
**Prevention:** Avoid using `innerHTML` for dynamic content insertion, especially when inserting user-controlled data into HTML attributes. Instead, use safer DOM manipulation APIs like `document.createElement()`, set properties directly (e.g., `img.src = item.url`), and add event listeners using `addEventListener()` or direct property assignment (e.g., `img.onclick = () => viewImage(item.url)`).
