## 2024-05-24 - DOM-based XSS via unescaped single quotes in encodeURIComponent
**Vulnerability:** A DOM-based XSS vulnerability was found in the gallery history rendering. User input (prompt) was encoded with `encodeURIComponent` and embedded in the `src` URL of an image. This URL was then assigned to `innerHTML` inside an `onclick='viewImage(...)'` attribute. Since `encodeURIComponent` does not escape single quotes (`'`), an attacker could input a single quote in the prompt, breaking out of the `onclick` attribute and executing arbitrary JavaScript.
**Learning:** `encodeURIComponent` is not sufficient for sanitizing data that will be placed inside single-quoted HTML attributes. Relying on it can lead to XSS.
**Prevention:** Avoid using `innerHTML` for dynamic content generation, especially with user-controlled data. Prefer safe DOM manipulation APIs like `document.createElement`, direct property assignments (`img.src = url`), and event listeners (`img.addEventListener('click', ...)`).
