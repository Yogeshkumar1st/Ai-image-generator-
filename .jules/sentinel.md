## 2025-02-27 - DOM XSS in Local Storage History
**Vulnerability:** The application was vulnerable to DOM-based Cross-Site Scripting (XSS) due to the use of `.innerHTML` to render generated images from `localStorage` in the gallery tab. User-controlled URLs containing XSS payloads (such as injected quotes breaking out of attribute context) could be executed when the gallery was loaded.
**Learning:** `encodeURIComponent()` does not escape single quotes (`'`). Since the image URLs were generated dynamically with `encodeURIComponent` but single quotes were left unescaped, an attacker could inject an XSS payload using single quotes which would then break out of the `onclick='viewImage("${item.url}")'` string interpolation when the `loadHistory` function rendered the history gallery using `.innerHTML`.
**Prevention:** Avoid using `.innerHTML` with interpolated strings for user-controlled data. Instead, use secure DOM manipulation APIs like `document.createElement`, directly assigning properties (like `img.src = item.url`), and passing data to event handlers using closures (like `img.onclick = () => viewImage(item.url)`).
