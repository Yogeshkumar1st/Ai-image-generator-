## 2024-05-24 - [XSS via unescaped single quotes in encodeURIComponent when using innerHTML]
**Vulnerability:** The gallery page was vulnerable to Cross-Site Scripting (XSS) because it interpolated user-generated data (`item.url`) directly into HTML attributes using `innerHTML` (`div.innerHTML = \`<img src="${item.url}" onclick="viewImage('${item.url}')">\`;`). Since the URL was generated by `encodeURIComponent(prompt)` earlier, single quotes were NOT escaped, allowing an attacker to inject arbitrary HTML attributes by adding single quotes to their prompt (e.g. `test' onerror='...`).
**Learning:** `encodeURIComponent()` in JavaScript does not escape single quotes (`'`). If an encoded string containing unescaped single quotes is interpolated into a single-quoted HTML attribute (like the `onclick` handler), it creates an XSS vulnerability, breaking out of the attribute context.
**Prevention:** Never use `innerHTML` string interpolation for user-generated content. Always use native DOM API methods (`document.createElement()`, `element.setAttribute()`, `element.src = ...`, `element.addEventListener()`) to ensure the browser handles encoding and prevents code execution natively.
