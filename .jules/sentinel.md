## 2024-05-18 - XSS in HTML string building with encoded URLs
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability existed where URLs from `localStorage` were inserted into the DOM using `innerHTML` and string interpolation, leaving them vulnerable to unescaped single quotes breaking out of the `onclick` attribute.
**Learning:** `encodeURIComponent()` (used earlier to encode the user prompt into the URL) does NOT escape single quotes (`'`). Thus, malicious single quotes embedded in the prompt pass through the image URL unharmed, allowing an attacker to break out of single-quoted HTML attributes (like `onclick='...'`) when the URL is later rendered via `innerHTML`.
**Prevention:** Avoid `innerHTML` entirely when handling user-influenced data, even if it has passed through some form of encoding like `encodeURIComponent()`. Always use secure DOM manipulation APIs like `document.createElement`, direct property assignments (e.g., `element.src`), and direct event bindings (e.g., `element.onclick = () => {...}`).
