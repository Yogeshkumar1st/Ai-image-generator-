## 2025-02-14 - DOM-based XSS via unescaped single quotes
**Vulnerability:** The `loadHistory` function used `innerHTML` to render image elements, where user-controlled `url` input was interpolated into the `src` and `onclick` attributes. Since JavaScript's `encodeURIComponent()` (used during generation) does not escape single quotes (`'`), an attacker could break out of the single-quoted `onclick` attribute and inject malicious JavaScript, leading to a DOM-based XSS.
**Learning:** `encodeURIComponent()` is insufficient for sanitizing data that will be placed within single-quoted HTML attributes. Direct DOM manipulation using `innerHTML` with unsanitized or insufficiently sanitized data is dangerous.
**Prevention:** Avoid `innerHTML` entirely when handling user-supplied or external data. Instead, use safer DOM APIs like `document.createElement`, direct property assignment (`img.src = item.url`), and setting event listeners directly (`img.onclick = () => viewImage(item.url)`).
