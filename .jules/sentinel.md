
## 2024-05-31 - DOM-based XSS via unescaped single quotes in encodeURIComponent
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability existed in `loadHistory` of `index.html`. The application used `encodeURIComponent` to process a user-provided prompt string in a Pollinations API URL. The URL was then saved to `localStorage` and later rendered into the DOM using `innerHTML`: `div.innerHTML = \`<img src="${item.url}" onclick="viewImage('${item.url}')">\`;`.
**Learning:** Standard JavaScript `encodeURIComponent` does *not* encode single quotes (`'`). Because the URL was interpolated into a single-quoted HTML attribute (`onclick="..."`), an attacker could inject an unescaped single quote into the prompt, break out of the string context in the `onclick` handler, and execute arbitrary JavaScript.
**Prevention:** Never use string interpolation (`innerHTML`) when rendering dynamic, user-controlled data into HTML attributes, regardless of prior generic URL encoding. Always use DOM API methods (e.g., `document.createElement('img')` and setting `img.onclick` directly via a function reference) to ensure the browser strictly treats the data as a value rather than executable code.
