## 2024-05-18 - [CRITICAL/HIGH] DOM-Based XSS in loadHistory
**Vulnerability:** Found a DOM-based XSS vulnerability in `loadHistory()` inside `index.html`. User-controlled URLs from `localStorage` were being directly injected into HTML strings using `innerHTML` within single quotes (`onclick="viewImage('${item.url}')"`). `encodeURIComponent` does not escape single quotes (`'`), allowing an attacker to break out of the HTML attribute and execute arbitrary JavaScript when the image is clicked.
**Learning:** Using `innerHTML` with unsanitized user data, especially when embedded in event handler attributes, is highly dangerous. Encoding functions like `encodeURIComponent` are not sufficient for HTML attribute context protection if they don't escape all relevant characters like quotes.
**Prevention:** Prefer safe DOM manipulation APIs like `document.createElement`, `element.setAttribute`, and direct property assignments (e.g., `element.onclick`) over `innerHTML` assignments when handling user-provided or stored data.
